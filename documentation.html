This webpage contains my documentation for Element 5 of the Amazing Elements!

Shapes and Textures

My element 5 scene contains various shapes in both of the scenes with textures applied to them. I used textures of the Iron Block from Minecraft to give my shapes a metallic look, one of the boxes also has an image of Pomni from The Amazing Digital Circus on it to add some diversity to the scene. All of the shapes are different and have varying sizes, I customised the settings myself using the shapes provided on the BabylonJS documentation website.

Heightmaps and Ground

Both scenes also have a floor which I have added a height map too that I found on the internet, I picked out a height map with an interesting layout to make the scene pop. Each scene uses the same height map but scene 2 uses a much more exaggerated version of the height map to make both of the scenes stand out from each other. Both height maps also use a texture of a retro 80s carpet, I picked different carpets for each scene to make them different from each other. I chose this texture because I thought it'd help highlight the various bumps in the height map due to the different variations on the texture. This height map was created with help from the BabylonJS documenation website and the previous work on heightmaps I learnt from the Element 2 scene. Keeping that previous work in mind it was quite simple to create a custom height map for my own version of Element 5.

Custom GUI

For this element, I used the provided code as a base which included 4 scenes. I reduced the amount of scenes to 2 and moved the buttons to better center them to the scene, I also cutomised the colours of the buttons to make them my own. I'm a big fan of the combination of Pink and Black so those are the two colours I decided to select for my element.
